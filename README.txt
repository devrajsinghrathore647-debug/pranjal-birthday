GITHUB PAGES:
1. Unzip this folder.
2. Create a new GitHub repository.
3. Upload ALL files from this folder (not the ZIP itself).
4. GitHub repo -> Settings -> Pages.
5. Source: Deploy from a branch -> main -> /(root) -> Save.
6. Open the Pages URL GitHub gives you.
